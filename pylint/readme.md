# pylint1.py

A simple Python script that defines an `add()` function and prints the sum of two numbers.

## Description

This repository contains a small example program demonstrating:

- defining a Python function
- returning a value from a function
- calling the function with two numeric arguments
- printing formatted output to the console

## Files

- `pylint1.py` � the main script that adds two numbers and prints the result.
- `readme.md` � this documentation file.

## Usage

Run the script with Python from the `pylint` folder:

```powershell
python pylint1.py
```

## Expected output

```text
The sum of 4 and 5 is 9
```

## Notes

- This example is intended for Python 3.
- The script uses the built-in `format()` method for string formatting.
